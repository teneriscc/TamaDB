Quarantine

Read-only inspection of quarantined payloads. Rejected documents are stored here when the quarantine policy permits it.

Quick Reference

MethodPathSummary
GET /api/v1/quarantine List quarantined entries
GET /api/v1/quarantine/{ref} Inspect a quarantined entry
GET

/api/v1/quarantine

List quarantined entries.

Query Parameters

FieldTypeRequiredDescription
rejectionTypestringNo"parse-error" | "validation-failure"
sourceIdentifierstringNoFilter by source identifier
limitintegerNoMaximum number of entries to return
offsetintegerNoNumber of entries to skip

Response

200 OK 
{
  "entries": [...],
  "count": 3
}
GET

/api/v1/quarantine/{ref}

Retrieve by reference ID (returned in error responses as quarantineRef).
